# Архитектура на проекта

## Трислойна архитектура

```
┌─────────────────────────────────┐
│  UI слой (Presentation)         │
│  ui.h / ui_display.cpp          │
│  ui_input.cpp                   │
│  - менюта, вход, изход          │
└────────────┬────────────────────┘
             │ извиква
┌────────────▼────────────────────┐
│  Логически слой (Logic)         │
│  logic.h / validation.cpp       │
│  book_ops.cpp / search.cpp      │
│  sort.cpp                       │
│  - валидация, търсене, сорт.    │
└────────────┬────────────────────┘
             │ извиква
┌────────────▼────────────────────┐
│  Слой данни (Data)              │
│  book.h / storage.h             │
│  storage.cpp                    │
│  - struct Book, файлове         │
└─────────────────────────────────┘
```

## Правила
- UI не чете файлове директно.
- Logic не печата нищо на екрана.
- Data не знае нищо за менютата.
